# Transforme-se-Advocacia-previdenciria
Projeto Integrador do Senac onde criamos a Lex Web, uma empresa de tecnologia formada por estudantes. Nosso projeto é desenvolver um site para uma cliente real da área de advocacia previdenciária, colocando em prática nossos conhecimentos de Front-End e aprendendo, na prática, como funciona o desenvolvimento de um projeto para um cliente.
